Overview

This documentation covers the technical implementation of the AI-Powered Portfolio System, including architecture decisions, code structure, and deployment instructions.

Quick Start: Clone the repository, set up environment variables, and run the development servers.

Tech Stack

Backend
  • Framework: FastAPI (Python)
  • AI: OpenAI GPT-4o-mini
  • Database: JSON files (development), PostgreSQL (production)
  • Server: Uvicorn
Frontend
  • Core: HTML5, CSS3, JavaScript (ES6+)
  • UI Framework: Bootstrap 5
  • Icons: Font Awesome 6
  • Charts: Chart.js (planned)

Key Design Decisions

Modular Architecture

Each component (AI Agent, Email Service, GitHub Service) is independently developed and tested.

Cost Optimization

Uses GPT-4o-mini for AI tasks and file-based storage for development to minimize costs.

Backend API

The FastAPI backend provides RESTful endpoints for all portfolio functionality.

API Reference

POST /chat - AI Chat

Main chat endpoint with conversation memory.

Request Body:
{
  "content": "Your message here",
  "session_id": "optional_session_id"
}
Response:
{
  "reply": "AI response here",
  "session_id": "session_id",
  "memory_count": 5,
  "status": "success"
}
POST /agent/task - AI Agent Task

Execute tasks using AI agent with tools.

Request Body:
{
  "task": "Analyze this code: print('Hello')"
}

Complete API documentation available at /docs when running locally (Swagger UI).

Deployment

Backend (Railway)

  1. Install Railway CLI: npm i -g @railway/cli
  2. Login: railway login
  3. Link project: railway link
  4. Deploy: railway up
  5. Set environment variables in Railway dashboard

Frontend (Vercel)

  1. Connect GitHub repository to Vercel
  2. Select frontend/ as root directory
  3. Configure environment variable: VITE_API_URL (your Railway URL)
  4. Deploy
Important: Update CORS settings in backend to allow your Vercel domain.
